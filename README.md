# Encaminha

Cole as anotações de uma reunião e receba as decisões, tarefas, responsáveis, prazos e pendências organizados.

**Abrir o app:** https://eneas-ena.github.io/encaminha/

## Como funciona

- App feito em página web; abre direto no navegador.
- Os dados ficam salvos só no próprio aparelho (não sincronizam entre aparelhos).
- Os serviços externos, como a inteligência artificial, passam pelo Worker `encaminha` no Cloudflare; as chaves secretas ficam guardadas lá, nunca neste código.

## Observações

- Projeto feito para a graduação em IA e Automação Digital (UniFECAF).

## Como publicar uma nova versão

1. Nesta página do repositório, clique em **Add file → Upload files**.
2. Arraste os arquivos novos, com os mesmos nomes dos antigos.
3. Clique em **Commit changes**.

Em um ou dois minutos a nova versão está no ar no mesmo endereço.
